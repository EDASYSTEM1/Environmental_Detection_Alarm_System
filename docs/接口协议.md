# 接口协议（冻结版 v1.0）

> 本文件是三个人并行开发的**唯一接口依据**。端口一旦冻结，任何人不得擅自修改；
> 要改必须先提，由组长更新本文件 + `top/sys_top.v`，再通知另两个人同步。
> 最后更新：2026-11-25

---

## 〇、全局约定（必须遵守）

| 项目 | 约定 | 原因 |
|---|---|---|
| 时钟 | 全系统**只有一个** 100 MHz `clk`（E3） | 多时钟 = 跨时钟域 = 三个人互相甩锅 |
| 时钟衍生 | **禁止**用分频器输出当时钟（不写 `always @(posedge clk_div)`） | 派生时钟会被 Vivado 报 clock 警告，时序分析不覆盖 |
| 节奏控制 | 用 `tick_xxx`（单周期使能脉冲）控制"多久做一次" | 单时钟域内最安全的做法 |
| 复位 | 内部 `rst` **高有效**，由 `rst_sync` 从 `~CPU_RESETN` 异步置位、同步释放 | 统一极性，避免"A 高有效、B 低有效" |
| 复位用法 | `if (rst) ... else ...` 同步复位写法 | 全组同一模板 |
| 数值格式 | 定点整数，缩放写死在端口名里（见第二节） | 避免三个人对"单位"理解不一致 |
| 数据更新 | 每 1 Hz 一次，配 `*_valid` 单周期脉冲 | 低速传感器不需要握手 |
| 模块命名 | `snake_case`，文件名 = 模块名 | 便于 `create_project.tcl` 用 glob 自动收文件 |
| 端口命名 | `方向_含义`：`din_` / `dout_` / `o_` / `i_` 可选，但同一模块内风格统一 | 可读性 |

**禁止事项**：跨模块用 `wire` 直接互相读内部信号（`u_b.internal_x`）。只能走端口。

## 二、数据格式（缩放约定，最容易出错的地方）

| 信号 | 类型 | 单位 | 例子 | 说明 |
|---|---|---|---|---|
| `temp_x10` | `signed [15:0]` | 0.1 ℃ | `253` = 25.3 ℃，`-52` = −5.2 ℃ | **有符号**，冬天室外可能为负 |
| `humi_x10` | `[15:0]` | 0.1 %RH | `550` = 55.0 %RH，范围 0~1000 | 无符号 |
| `lux` | `[15:0]` | 1 lux | `320` = 320 lux | 无符号，B 负责把 ADC 原始值换算成 lux |
| `adc_raw` | `[11:0]` | 原始码值 | 0~4095 | ALS 的 12 位 ADC，调试用 |
| `*_status` | `[7:0]` | 位标志 | 见第三节 | 0 = 正常 |

**为什么不用 BCD**：BCD 是"显示格式"，属于我（显示）的活。传感器和报警只输出二进制定点数，
这样 B 不用关心数码管怎么画，我改显示也不用动 B 的代码。

## 三、状态字 `status[7:0]` 定义（统一）

| 位 | 名称 | 含义 |
|---|---|---|
| 0 | `ST_VALID` | 至少成功读到过一帧数据 |
| 1 | `ST_NACK` | I2C 从机无应答 / SPI 无响应 |
| 2 | `ST_TIMEOUT` | 通信超时（超过约定时钟数没有回数据） |
| 3 | `ST_BUSY` | 上电初始化未完成（前 100 ms 会有） |
| 7:4 | 保留 | 各模块自定义调试位，**不要**给报警模块用 |

`th_status == 0` 表示温湿度正常。快照模块把两路状态汇总成：

```
sensor_status[0] = th_ok      // 温湿度正常
sensor_status[1] = ls_ok      // 光照正常
sensor_status[2] = th_stale   // 连续 3 个采样周期没拿到数据
sensor_status[3] = ls_stale
```

## 四、五个模块的冻结端口

### 4.1 `th_sensor`（成员B：Pmod HYGRO，I2C）

```verilog
module th_sensor (
    input  wire               clk,
    input  wire               rst,
    input  wire               sample_tick,   // 1 Hz 单周期脉冲：该采样了
    output wire               scl,           // I2C SCL（100 kHz，由 100 MHz 分频）
    inout  wire               sda,           // I2C SDA（开漏，模块自带上拉，必须 inout）
    output reg  signed [15:0] temp_x10,
    output reg         [15:0] humi_x10,
    output reg         [7:0]  status,
    output reg                valid          // 采完一帧的 1 拍脉冲
);
```

**接口语义**：`sample_tick` 来了开始一次"读温湿度"事务；事务结束那拍 `valid` 拉高 1 拍，
同时更新 `temp_x10/humi_x10`。没拿到数据时**不要**更新数值，只置 `status[1]`。

---

### 4.2 `light_sensor`（成员B：Pmod ALS，SPI）

```verilog
module light_sensor (
    input  wire        clk,
    input  wire        rst,
    input  wire        sample_tick,
    output wire        als_cs,      // 低有效片选
    output wire        als_sclk,    // SPI 时钟（建议 1 MHz 以下）
    input  wire        als_miso,    // ADC 数据，MSB 先出
    output reg  [11:0] adc_raw,
    output reg  [15:0] lux,
    output reg  [7:0]  status,
    output reg         valid
);
```

**接口语义**：同 4.1。`lux` 是由 `adc_raw` 按曲线换算出的照度（换算表写在自己模块里，
并在自己 README 里写清楚，方便报告画图）。

### 4.3 `alarm_ctrl`（组长：阈值判定 + 人机交互）

```verilog
module alarm_ctrl (
    input  wire               clk,
    input  wire               rst,
    input  wire               sample_tick,
    input  wire signed [15:0] temp_x10,
    input  wire        [15:0] humi_x10,
    input  wire        [15:0] lux,
    input  wire        [7:0]  sensor_status,   // 快照汇总（第三节）
    input  wire        [15:0] sw,
    input  wire        [4:0]  btn,             // 已消抖
    output reg  [3:0]  alarm_level,            // 0 正常 / 1 注意 / 2 警告 / 3 严重
    output reg  [3:0]  alarm_src,              // bit0 温度 / bit1 湿度 / bit2 光照 / bit3 传感器故障
    output reg  [15:0] led,
    output reg         aud_pwm,                // 蜂鸣器 PWM（约 2 kHz）
    output reg         aud_sd                  // 音频使能，必须为 1
);
```

### 4.5 `vga_disp`（成员C：VGA 640×480 外接显示器）

```verilog
module vga_disp (
    input  wire               clk,            // 100 MHz（不要自己产生像素时钟！）
    input  wire               rst,
    input  wire signed [15:0] temp_x10,
    input  wire        [15:0] humi_x10,
    input  wire        [15:0] lux,
    input  wire        [3:0]  alarm_level,
    input  wire        [3:0]  alarm_src,
    input  wire        [15:0] sw,
    output reg  [3:0]         vga_r,
    output reg  [3:0]         vga_g,
    output reg  [3:0]         vga_b,
    output wire               vga_hs,
    output wire               vga_vs
);
```

**接口语义**：`vga_hs/vga_vs` 已经由 `common/vga_timing.v` 产生（模块内部例化了它），
C **只需要**在 `pix_en` 那拍按 `x/y` 给出颜色。像素时钟不用管，也不许自己造时钟。

## 五、开关 / 按键 / LED 分配

### 5.1 拨码开关 `sw[15:0]`（阈值设定，报警模块用）

| 开关 | 含义 | 计算 |
|---|---|---|
| `SW[3:0]` | 温度上限 | `20 + n×2` ℃，即 20/22/…/50 ℃ |
| `SW[7:4]` | 湿度上限 | `40 + n×5` %RH，即 40/45/…/115 %RH |
| `SW[9:8]` | 光照下限（太暗报警） | `20 / 40 / 80 / 160` lux |
| `SW[10]` | 蜂鸣器使能 | 1 = 允许响 |
| `SW[11]` | 静音 | 1 = 强制不响（演示用） |
| `SW[12]` | 自检模式 | 预留（假数据演示） |
| `SW[15:13]` | 保留 | — |

> 注意：`SW[8]`、`SW[9]` 在 1.8 V bank，XDC 里必须是 `LVCMOS18`，别改。

### 5.2 按键 `btn[4:0]`（已过 10 ms 消抖）

| 位 | 板载键 | 引脚 | 建议用途 |
|---|---|---|---|
| `btn[0]` | BTNC | N17 | 报警确认/清音 |
| `btn[1]` | BTNU | M18 | 切换显示页 |
| `btn[2]` | BTND | P18 | — |
| `btn[3]` | BTNL | P17 | — |
| `btn[4]` | BTNR | M17 | — |

### 5.3 LED `led[15:0]`

| 位 | 含义 |
|---|---|
| `LED[3:0]` | `alarm_level`（0~3） |
| `LED[7:4]` | `alarm_src`（温度/湿度/光照/故障） |
| `LED[8]` | 蜂鸣器正在响 |
| `LED[15:9]` | 保留（后面可做数值条形图） |

## 六、显示内容规范（两边必须一致）

屏幕布局统一成 **4 行 × 16 字符**（OLED 128×32 正好 16×4 个 8×8 字；VGA 也按同样文字内容放大画）：

```
第 1 行:  ENV MONITOR          ← 固定标题
第 2 行:  T:25.3C H:55.0%      ← 温度/湿度
第 3 行:  L:320lx  ALM:2       ← 光照 + 报警等级
第 4 行:  OK  / SENSOR FAIL    ← 状态（传感器故障时显示 FAIL）
```

- 数值格式化：温度一位小数（负号占位），湿度一位小数，光照取整；
- 报警等级显示成 `ALM:0..3`，等级 ≥2 时第 4 行显示 `ALARM!`；
- 两边字形都用 `common/font_rom.v`（8×8 点阵，从 v2 复用），保证 OLED 和 VGA 的字形一致。

## 七、端口变更流程（唯一合法路径）

1. 在群里说明"要加/改哪个模块的哪个端口，为什么"；
2. 组长确认后改 `top/sys_top.v` + 本文件，**同一次提交**里完成；
3. 另外两人 `git pull` 后重新跑一次 `source scripts/create_project.tcl`（新增文件要重新收）；
4. 任何人不得在自己分支里私改 `sys_top.v`。
