# docs/ 文档索引

> 本目录放"给人看"的东西：接口、分工、引脚、组规。
> 代码在 `top/` `common/` `modules/`，脚本在 `scripts/` `tools/`。

## 哪个文件是"唯一依据"

| 文件 | 地位 | 谁会改 |
|---|---|---|
| **`接口协议.md`** | ★ **唯一依据**（端口/数据格式/开关映射/显示规范） | 只有组长，且要连同 `sys_top.v` 一次提交 |
| `团队约定.md` | ★ 组规（每人只改自己目录、接口冻结、时钟复位等） | 组长，组内讨论后 |
| `分工与流程.md` | 分支模型、PR 清单、每日流程 | 组长 |
| `引脚分配.md` | 引脚速查 + Pmod 接线说明（给成员B） | 组长 |

## 接口协议的三个版本

| 文件 | 用途 | 说明 |
|---|---|---|
| `接口协议.md` | 改内容用 | GitHub 上能直接预览，diff 清楚 |
| `接口协议_v1.1.docx` | 组员要往里加说明、老师要 Word 格式时 | **导出物，不要直接改** |
| `接口协议_v1.1.pdf` | 发微信群、打印贴工位 | **导出物，不要直接改** |

> ⚠️ **只改 `.md`，然后重新导出 docx/pdf**。
> 直接改 docx 会让三个版本不一致，组员拿到的可能就是旧版本。
